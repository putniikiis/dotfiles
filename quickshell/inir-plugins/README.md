# inir-plugins

Self-contained Quickshell config for iNiR plugins / settings IPC.

Live path: `~/.config/quickshell/inir-plugins` → this directory.

Started by: `systemctl --user start inir-plugins.service` (`qs -c inir-plugins`).

User plugin data / settings still live under `~/.config/angelos/` (settings.json, enabled plugins).
